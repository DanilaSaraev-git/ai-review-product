## Граница с техническим репозиторием

Код, контракты, архитектура, технические спецификации, CI и deployment развиваются в [`ai-review-platform`](https://github.com/DanilaSaraev-git/ai-review-platform). Эта база не требует его клонирования для работы с гипотезами, источниками или материалами MTS.

В продуктовую базу не копируются приложения, пакеты, контрактные схемы, Spec Kit и implementation. Здесь остаются только продуктовые выводы, клиентские источники, эксперименты и концепты. Ссылка между репозиториями — опубликованные contract/release URL, не submodule.

## Политика артефактов

В Git не коммитятся виртуальные окружения, веса моделей, кэши, байткод, локальные журналы и воспроизводимые загрузки. Оригинальные исследовательские источники сохраняются только когда они нужны для доказательной базы и их происхождение отражено в [реестре источников](knowledge/sources.md). Производные файлы должны быть помечены как производные.

Эксперимент Docling/pdfplumber объёмом около 1,6 ГБ намеренно не входит в эту базу и не переносился при разделении репозиториев.
