# ТЗ. Ежедневная витрина утилизации сот

## Общие сведения

Витрина содержит ежедневную сводку нагрузки на соты сети радиодоступа: число сессий, число уникальных абонентов и объём трафика в разрезе региона, соты и вендора оборудования. Используется службой планирования сети для выявления перегруженных участков.

## Алгоритм расчёта

### Шаг 1. Отбор событий

Берутся все события за FIELD_BIZ_DATE из TABLE_IUM_RAW_PS, TABLE_IUM_RAW_MS и TABLE_QOS_RAW. Исключаются тестовые и служебные записи.

### Шаг 2. Определение соты и региона

Для каждой пары «абонент — сота» за сутки находится последняя запись с ненулевыми FIELD_LAC и FIELD_CELL_ID.

Сопоставление с TABLE_BS_REF выполняется по приоритету:

- по паре (lac, cell_id)
- по lac (последняя актуальная запись за сутки)
- по cell_id только для 4G (FIELD_CELL_GEN = 4)
- если lac = 0 → join только по cell_id (4G)
- если cell = 0 → join только по lac

Убираются дубли: на выходе одна region_code на соту. Далее присоединяется FIELD_REGION_NAME из TABLE_REGION_REF.

### Шаг 3. Определение вендора

Для соты берётся последнее значение vendor_name из TABLE_BS_REF за сутки.

### Шаг 4. Агрегация

Группировка по:

- FIELD_REGION_NAME
- FIELD_CELL_ID
- FIELD_VENDOR_NAME
- FIELD_SESSIONS_CNT = count(*)

### Шаг 5. Расчёт часа наибольшей нагрузки

FIELD_BUSY_HOUR определяется как час с максимальным числом сессий по соте за сутки.

### Шаг 6. Запись в CDM

Данные записываются в TABLE_AGG_CELL_LOAD.
